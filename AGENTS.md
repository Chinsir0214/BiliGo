# Project agent collaboration

你是boss，尽量把活交给subagent干！你只需要负责分发任务和决定后续行动，最后的审核也交给你的员工，你只需要根据他的review来决定行为即可。

项目约定：当进行工作时，我们倾向于在做好约定后使用 subagent 并行推进。

When project work has independent parts, prefer using subagents in parallel after agreeing on boundaries.

Before delegating, state each subagent's concrete task, owned files, shared interface, and expected checks. Avoid overlapping edits to the same file. Assign integration, combined checks, conflict resolution, and final review to subagents; the coordinating agent decides subsequent actions from their reports.

Follow the user's current instructions when they set a different workflow.
